## 👋 About me

I'm **Ananth**, a **Founder & Senior Software Developer** with **5+ years of Angular development experience**. I focus on building beautiful, maintainable web and mobile software that balances user experience, performance, security and real-world usefulness.

- 🏗️ **Building:** PicSecure products, PG Management, Svara AI assistant and useful mobile utilities
- 💻 **Core:** Angular, TypeScript, JavaScript, HTML, CSS, RxJS and modern frontend architecture
- 📱 **Cross-platform:** Ionic, Capacitor, Progressive Web Apps and native Android integrations
- ☁️ **Backend & cloud:** Firebase, cloud integrations, data access design and security-minded engineering
- 🌱 **Expanding:** Java, Spring Boot, offline-first assistant features and scalable application architecture
- 🎯 **Engineering values:** Clarity, accessibility, performance, reliability and privacy by design
